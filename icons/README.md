# 앱 아이콘 (공식 로고 넣는 곳)

이 폴더에 아래 이름으로 **정사각 PNG**(256×256 이상 권장, 모서리는 둥글게 처리하지 않은 원본)를 넣으면
앱이 자동으로 그 이미지를 씁니다. 파일이 없으면 앱 안에 들어 있는 기본 그림이 나옵니다.

| 파일 이름 | 쓰는 곳 |
|---|---|
| `amap.png` | 고덕지도 (高德地图) |
| `didi.png` | DiDi (滴滴出行) |
| `applemaps.png` | 애플지도 |
| `wechat.png` | 위챗 |
| `googlemaps.png` | 구글 지도 (울란바토르) |
| `ubcab.png` | UBCab (울란바토르) |

각 로고의 저작권·상표권은 해당 회사에 있습니다. 회사 내부에서 "이 앱을 연다"는 표시용으로만 쓰세요.
